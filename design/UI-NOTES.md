# 性能面板 UI / 2026-09-22

## 参考与适用范围

- [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：透明材质、内容与上层控件的关系。
- [Apple 官方桌面透明组件示例](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)：查看官方 clear-look 截图，参考背景保留、低对比边缘与文字层级。
- [shadcn dashboard](https://ui.shadcn.com/examples/dashboard)：借鉴标签、突出数值、辅助说明的排版顺序。

以上仅作为设计参考；没有复制其源码、图片、字体或品牌素材。这里实现的是 Java2D 静态透明浮层，没有声称实现 Apple Liquid Glass 的折射或动态材质。

## 本版规范

画布为 1200×900。顶部不绘制品牌文字，生成时间放入底部诊断栏并右对齐，诊断文字按时间宽度预留 32px 间距。圆角玻璃标题栏（x76、y136、1048×72，圆角半径 36px）内“服务器状态”居左、服务器名称居右，不再显示“单服实时监控”或重复大标题。左侧圆形主视图突出 TPS，右侧四项指标各自包含标签、数值、说明及占比线。主色为白，薄荷青仅用于状态和进度。中文使用真实的无衬线字体，数字使用 Segoe UI 或当地可用的无衬线字体。

浮层不是深色遮罩。标题栏、圆形仪表、四张指标卡和诊断栏使用从浅灰白到冷灰的低透明度纵向材质，默认强度 12%，并用一条低对比亮边表达材质边界；底图颜色和轮廓应清楚透出。为稳定白字，底图第 85 百分位亮度会决定一层轻度全局中性压暗，最大 38%，而不是逐卡片加黑。文字使用轻微暗色阴影承托。指标组件圆角半径为 50px。默认关闭底图模糊；用户仍可开启可分离高斯模糊，启用后只在组件形状内部合成。可选模糊和背景适配均在初始化时计算，避免每次请求重复分析。

`renderOverlay` 可输出透明的信息层（文字、填充和描边），不包含依赖底图的模糊。预览命令额外生成透明 PNG 和纯色衬底校样；纯色是检查 UI 的衬底，不是替用户生成的新背景。

测试验证组件之间的像素保持原背景值、透明层留白 alpha 为零，以及组件内部 alpha 与配置相符。生成图已目视检查字体、对齐、指标和单位位置。QQ 实服发送效果仍需部署后检查。
